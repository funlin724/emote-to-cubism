# examples/

本目录预留**自绘占位角色**的端到端示例（CC0/自制美术走完整条管线，
证明工具可用且不含任何 IP 美术）。

## 规划内容

- `fixture/`：用 FreeMote `PsBuild` 或自写回器生成的 E-mote 结构测试数据
  （格式不受版权保护，自造数据 100% 可入库）；
- 一个最小占位角色：几个色块部件 + 眨眼/口型图标，覆盖
  parse → assemble → build_moc3 → 运行时验证全流程；
- CI 会用该 fixture 做冒烟测试。

**注意**：官方 E-mote 样例数据通常只授权评估用途，上传前必须逐条读
EULA；不允许再分发的一律不进仓库（见 `../ASSETS_POLICY.md`）。
示例尚未就绪——当前仓库状态为工具 + 文档先行。
