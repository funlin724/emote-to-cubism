# Editor 真值模型制作菜谱（v2，按实机 5.3 逐项核验）

> 目的：破解 moc3"变形器+绑定"的接线语义，用官方 Editor 造**最小标准答案**。
> 导出的最小 moc3（1 网格 + 1 变形器 + 1 绑定）是写生成器时逐字段对照的
> 权威参照。按本文可 3 分钟复现一个真值模型。

## 开始前

- 工作目录 + 测试图（如 116×96 RGBA 的 src.png）。
- Cubism Editor（实测 5.3.03，PRO 个人版，简体中文界面；旧版菜单名不同）。

## 环境设置里的两个开关（影响操作体验）

- 文件 → 环境设置 → 文件：
  - "对文件进行另存时，在名称的末尾添加编号"= **开** → 另存对话框会预填
    `xxx0.cmo3` 这种名字，**需手动改成目标名**。
  - "保存/导出后打开保存目标的位置"= **开** → 每次保存/导出后弹资源管理器
    抢前台，关掉即可。

## 坑 1（致命）：导出前必须先生成纹理集

**症状**：文件 → 导出运行时文件 → 导出为moc3文件... 后只弹一个信息对话框
"**纹理集生成后调用**"（日文原文"テクスチャアトラスを生成してから
呼び出してください"），点确定后什么都不会发生，日志无导出记录。

**解法**：导出前先做一次

1. 菜单 **建模 → 纹理 → 编辑纹理集...**（快捷键 **Ctrl+T**）；
2. 弹"新纹理集设置"：名称 `TextureAtlas1`、宽高 1024px，默认点 **OK**；
3. 进入"编辑纹理集"窗口，画布上自动排入模型图像（能看到 src 缩略图即成功），
   点 **OK** 关闭。

之后导出才会正常弹"导出设置"对话框。每个工程做一次即可（跟着 cmo3 走，
另存后的新工程不用重做）。

## 坑 2：moc3 导出的真实菜单路径

```
文件 → 导出运行时文件 → 导出为moc3文件...    （快捷键 Ctrl+Alt+S）
```

"导出设置"对话框里：

- **输出版本**：下拉选 **"适用于SDK 4.0 / Cubism 4.0"**
  （可选 3.0(3.2) / 3.3 / 4.0 / 4.2 / 5.0 / 5.3，会记住上次选择）；
- 其余保持默认（userdata3.json、cdi3.json、防漏色处理勾着，physics 不勾）；
- 点 OK 后系统保存对话框，文件名预填 `<工程名>.moc3`，保存。

**产物清单**：`<名>.moc3`、`<名>.model3.json`、`<名>.cdi3.json`、贴图目录。

## 坑 3：变形器的创建入口不在部件面板右键

部件树右键菜单里**没有**"新建变形器"。实际入口：

```
建模 → 变形器 → 创建弯曲变形器... / 创建旋转变形器...
```

流程：

1. **先在部件树单击选中目标绘图网格**（不是图像文件节点）；
2. 打开上述菜单项，弹"创建××变形器"对话框；
3. "添加到"保持默认 **"设为所选对象的父级"**；
4. 弯曲变形器的"转换的分割数量 5×5 / 贝塞尔分区 2×2"保持默认；
5. 点 **创建**，然后 **关闭**（别点成"连续创建"再关，会留在对话框）。

## 坑 4：没有"追加关键形"单键按钮，改用"新增2个键"

参数面板头部小图标：▷（播放）、**新增2个键**、**新增3个键**、删除键、
手动调整键…… 实际打法：

1. **先选中目标变形器**（部件树点它的名字）；
2. **单击参数面板里 `角度 X` 行的名字**选中（行上出现细蓝框）；
3. 点 **"新增2个键"** → 滑杆两端各打一个关键形（绿色菱形）；
4. 点该行数值框输入 `30` 回车（跳到 +30 键，菱形变橙红 = 踩在键上）；
   - **旋转变形器**：检视面板把"角度"字段改成 `15` 回车；
   - **弯曲变形器**：画布上拖它网格框的角点放大/挪动；
   - 关键形实时记录——当前参数值正好有键，所有修改直接写进该键。

验证：滑杆两端绿色菱形 = 有键；踩在键上时变橙红。

## 自动化备注（CUA/桌面自动化时）

- 缩放坐标下发参数面板存在**命中行整体向下偏一行**现象：点"角度X行"
  实际选中角度Y。自动化需先点行、截图核对蓝框再操作；人手无此问题。
- 导出/保存后弹的资源管理器抢焦点，每步后要重新激活编辑器。
- PowerShell 坐标点击对 Swing 菜单不可靠；UIA 需 Java Access Bridge。
  Editor 支持键盘全流程（Alt 激活菜单 → 方向键 → Enter）。

## 复现/加做（每次 3 分钟）

1. 打开上一版 cmo3，文件 → 另存... → **手改文件名**；
2. 选中网格 → 建模 → 变形器 → 创建××变形器 → 创建 → 关闭；
3. 选角度X 行 → 新增2个键 → 数值框输 30 → 改变形器姿态；
4. Ctrl+S 保存，Ctrl+Alt+S 导出 → 确认版本 4.0 → OK → 回车保存。

## 卡住了怎么办

- 弹"纹理集生成后调用" → 先做"坑 1"，别重复点导出；
- 点错了 Ctrl+Z；实在乱了删掉工作目录重来，没有风险。

## 对照解析

用 `tools/dump_moc3.py <真值>.moc3` dump 全部关键段，重点核对：
- deformer 三段（band/begin/counts）的精确字段值与排列；
- keyform_position_begin_indices 的单位与填充规律（64-float 对齐）；
- keyform_counts 与绑定 keys 数的对应关系；
- SOT 段顺序与写出器布局顺序的逐项核对。
